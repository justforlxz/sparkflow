# 0009 图片阶段从「重绘场景」改为「提取目标」

- 状态：已采纳（2026-11-20）
- 取代：ADR 0008 中「按视觉方向重绘成品图」的部分（一图对一图与单任务执行保留）

## 背景

第一版图片阶段的目标是「把原图重绘成一张可以直接发布的新图」：保留主体、改背景与光照、
按视觉方向（清新生活感/杂志视觉/产品质感）调性输出。

实际使用场景变了：用户要的不是「换背景的同类照片」，而是**把场景里的某个目标单独取出来**——
例如一张书桌照片，要的是那块桌垫的织物纹理、材质与图案，做成可以直接当素材用的图片。

「重绘」与「提取」是两种相反的动作：重绘乐于改变与美化，提取要求不改、只搬运。

## 决策

1. **资源夹新增「提取目标」字段**（`media_collection.extract_target`，文本，可空）：
   描述要从素材里取出什么，例如「桌垫的织物纹理」。同批素材通常服务同一个产品，所以放在资源夹上，
   而不是每次创作重填；发起创作时该字段必须非空。
2. **输出形态固定为去透视的平铺素材图**：只保留目标本身，画面里没有桌面、道具、背景与边缘阴影；
   目标拉平成正面视角、四边完整、铺满画面。不做「保留原视角的裁剪」。
3. **任务的「视觉方向」改名为「提取要求」**，取值改为三项：
   `faithful`（忠实还原）、`flatten`（平整化）、`dereflect`（去反光）。
   原三项（清新生活感/杂志视觉/产品质感）删除。
4. 一图对一图、单任务执行、失败只重试失败阶段等既有规则不变。
5. 文案阶段依据改为：资源夹来源信息 + 提取目标 + 视觉提取出的目标材质特征 + 提取出的素材图数量。

## 后果

- 收益：产物从「看起来像的图」变成「能直接用的材质」，符合真实用途。
- 代价：`generated_asset` 的图片语义从「成品图」变为「素材图」，界面文案要跟着改
  （「创作结果」的措辞、发布准备的说明）；已有历史结果仍按旧语义展示，不做迁移。
- **能力风险**：图生图模型天然倾向「生成」而非「忠实复制」。提取效果取决于模型能否守住
  「不改结构、只搬纹理」。这一点必须在真实模型上验证，不能靠提示词保证。

## 备选与放弃原因

- 保留原视角的裁剪：省事，但得到的是带角度的照片局部，不能当材质用。
- 每次创作临时填提取目标：同一批素材要重复填，容易填歪。
- 让模型自己判断该提取什么：不可控，同一张图每次结果不同。
