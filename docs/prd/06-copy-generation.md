# 06 文案创作

> 依赖：02 网关、03 Agent 配置、05 提取、12 素材库与版本
>
> **输入来源已变**（ADR 0010）：不再是「本次任务的全部提取图」，而是**用户在发布页选中的素材**
> （可来自不同类别、不同提取运行）。产物是一条 `copy_version`。

## 目标

用「文案创作 Agent」的配置，结合原始素材与本次生成的图片，产出标题、正文、话题标签三个字段。

## 范围

包含：prompt 拼装、结构化输出解析、字段校验、失败分类、禁止照搬与编造的内容约束。

不包含：多轮改写对话、按平台改写多个版本。

## 设计契约

### 输出结构

MUST：模型必须返回可解析的 JSON：

```json
{ "title": "≤ 20 字的标题", "body": "正文，分段用 \n\n", "tags": ["标签1", "标签2"] }
```

解析规则（MUST）：

1. 允许模型把 JSON 包在 ```json 代码块里，解析前剥离围栏。
2. 解析失败 → 按「格式异常」处理：`error.code = "COPY_FORMAT"`，不写入结果。
3. `tags` 接受数组或 `#标签 #标签` 字符串两种形态，统一清洗为不含 `#` 的数组，去重，最多 10 个。
4. `title` 去空白；`body` 保留换行但压缩连续空行到最多一个空行。
5. 三个字段都为空或 `title` 为空 → 视为失败，不产出结果。

### 输入拼装

### 视觉提取（本次新增，必须先做）

文案要围绕**提取目标**来写（例如这块桌垫是什么材质、什么图案），所以生成文案前先对**每一张原始图片**做一次视觉提取，重点是目标本身的特征：

- 输入：原图（压缩后）+ 一句话要求「用中文写出照片里『提取目标』的材质、纹理、图案与颜色，两句话以内」；
- 输出：每张原图一条 1–2 句的中文描述，按原图顺序编号；
- 提取用独立的**图片理解网关**（`protocol = magpie-vision`，工具 `analyze_image{image, prompt}`），
  不要求文案模型自己具备 `image_input` 能力；
- 提取结果、资源夹来源信息、每张成品图对应的原图编号一起进文案提示词。

若未配置可用的 `magpie-vision` 网关，或某张图的识别失败：允许继续生成文案，但必须在任务详情
与结果上标注「未包含照片内容」，不得静默降级，也不得改用文案模型猜图。

### 输入拼装

MUST：输入必须包含五部分，且各自可单独调整而不改流程：

1. Agent 快照里的 `role`、`systemPrompt`、`outputRequirements`。
2. 资源夹的来源信息：平台、原始标题、原始文案（作为**参考意见**，不是待改写文本）。
3. 本次生成的每张成品图（按原图编号），以及上一步的每张原图视觉描述。
4. 任务参数：文案风格、补充要求。

SHOULD：prompt 模板放在 `src/modules/copy-generation/prompt.ts`，模板变量显式声明，便于单测断言。

### 内容约束

MUST NOT：

- 不得照搬原始文案（要求模型重写；验收里有相似度人工检查项）。
- 不得编造商品参数、功效、价格、个人使用体验。
- 不得在解析失败时把模型原文当正文塞进结果。

MAY：返回前做一次长度截断保护（标题 > 40 字截断并记日志）。

## 数据与接口

写入 `generation_result`：title、body、tags（text[]）、visual_style

失败分类：`COPY_TIMEOUT`、`COPY_AUTH`、`COPY_FORMAT`、`COPY_EMPTY`、`COPY_REJECTED`。

## 验收标准

| 编号 | 断言 | 自动化用例 |
| --- | --- | --- |
| AC-06-1 | 正常返回时，结果里 title/body/tags 三个字段都有值，tags 已去重且不含 `#` | `src/modules/copy-generation/*.test.ts` |
| AC-06-2 | 返回带 ```json 围栏时能正确解析 | 同上 |
| AC-06-3 | 返回非 JSON 时任务记 `COPY_FORMAT`，结果不写入脏数据 | 同上 |
| AC-06-4 | `tags` 给成 `#a #b` 字符串时能解析成数组 | 同上 |
| AC-06-5 | 上游 401 时错误码为 `COPY_AUTH`，消息可读且不含密钥 | 同上 |
| AC-06-6 | 真实生成一次，人工核对：正文与原始文案不雷同、无编造参数 | 人工（写入验收记录） |
| AC-06-7 | 3 张原图 → 3 条视觉描述，且都出现在文案请求里（按原图编号对齐） | 单测 |
| AC-06-8 | 未配置 `magpie-vision` 网关或识别失败时，结果上出现「未包含照片内容」标注，任务仍可完成 | 单测 |

## 验证方式

```bash
pnpm test        # 解析、清洗、错误分类、prompt 拼装
pnpm test:e2e    # 用 mock 适配器跑任务链路（与 04 共用）
```

人工项：用真实的文案模型对一个资源夹生成一次，按 AC-06-6 核对并记录。
