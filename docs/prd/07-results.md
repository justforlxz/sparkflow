# 07 任务与结果界面

> 依赖：02、03、04、05、06 ｜ 页面功能

## 目标

让用户看清「每次创作干了什么、卡在哪、产出了什么」，并能重试失败阶段、重新生成、编辑与删除结果。

## 范围

包含：任务列表、任务详情（两阶段状态、失败原因、重试次数）、资源夹详情里的「AI 创作结果」页签、
结果编辑、结果删除、重试与重新生成入口。

不包含：手动新建结果、结果版本历史。

## 设计契约

### 任务列表（`/tasks`）

每行展示：资源夹名称、创建时间、提取要求 + 文案风格、预计提取图张数、**两个阶段各自的状态**、
派生任务状态、失败原因摘要、进入结果 / 重试 / 重新生成的入口。

MUST：

1. 阶段状态必须分别可见（生图 / 文案各一个标签），不能只给一个总状态。
2. 失败阶段旁必须出现「重试」按钮；「重试」只作用于失败阶段（语义见 ADR 0005）。
3. 「重新生成」按钮点击后先弹出确认，说明「将重新执行生图与文案两个阶段并产生新结果」，
   确认后才新建任务；取消不产生任何请求。
4. `queued`/`running` 时每 3 秒轮询一次，进入终态后停止轮询，离开页面清理定时器。

### 页面结构以 `docs/prd/12-asset-library.md` 为准

资源夹详情改为三个页签：**原始素材 / 素材库 / 发布**（ADR 0010）。
下面「AI 创作结果」一节描述的是上一版的两页签结构，仅保留其结果卡片与折叠交互的细节约定，
页签归属与进度位置按 12 执行。

### 资源夹详情的「AI 创作结果」页签（上一版结构，细节仍适用）

**原始素材页签只放原图与来源信息**：不显示任务进度、不显示创作结果、不显示「开始 AI 创作」以外的东西。
进度与结果**全部**收进「AI 创作结果」页签，两个页签各管一件事。

「AI 创作结果」页签内的 MUST：

1. **进行中任务在最上面**：该资源夹所有 `queued`/`running` 任务置顶展示，两个阶段状态各自可见，
   生图阶段显示「正在生图 第 k/N 张」；
2. **失败 / 部分失败的任务**紧随其后，带可读原因；只有真的失败阶段才给「重试」；
3. **结果默认折叠**：每条结果只显示一排提取图缩略图（按原图顺序）+ 一行摘要
   （生成时间、张数、状态、**提取目标**）；
4. **点击展开**：展开后显示标题、正文、话题标签，以及「编辑」「整理发布」按钮；
5. 折叠状态存本地（同一浏览器刷新后保持），不落库；
6. 空状态：没有任务也没有结果时，显示「开始 AI 创作」引导，不显示空白页签。

### 图片预览（全站统一）

MUST：

1. 任何位置点击图片缩略图都在**站内弹窗**里看大图，**不得**打开新标签页（`target="_blank"` 一律禁止）；
2. 适用位置：资源夹详情的原始素材、AI 创作结果（折叠态与展开态）、发布准备弹窗、任何后续新增的图片列表；
3. 弹窗要有：关闭按钮、`Esc` 关闭、点遮罩关闭、焦点回到触发它的缩略图；
4. 大图用原图地址（不是缩略图地址），并在弹窗里显示文件名；键盘可达（缩略图本身是按钮，不是 `<a>`）。

### 通用

MUST NOT：

- 不得在前端根据状态自行推断「已发布」。
- 不得在编辑结果时修改任务快照或原始素材。
- 不得为实时性引入 WebSocket/SSE（轮询够用）。
- 不得在重试按钮上做「重试整个任务」的隐式行为。

SHOULD：

- 空状态直接引导「开始 AI 创作」，不写「暂无数据」。
- 图片网格统一走缩略图参数（`?w=400`）。

## 数据与接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/tasks` | 列表（派生状态 + 两阶段状态 + 错误摘要） |
| GET | `/api/tasks/[id]` | 详情（阶段、快照、结果 id、attempts） |
| POST | `/api/tasks/[id]/retry` | 只重试失败阶段 |
| GET | `/api/collections/[id]/results` | 资源夹结果列表 |
| PATCH | `/api/results/[id]` | 编辑结果 |
| DELETE | `/api/results/[id]` | 删除整组结果（连带发布记录） |

## 验收标准

| 编号 | 断言 | 自动化用例 |
| --- | --- | --- |
| AC-07-1 | 无任务时列表显示空状态与入口，不显示假数据 | `tests/e2e/results.spec.ts` |
| AC-07-2 | 任务列表同时显示生图阶段与文案阶段的状态标签 | 同上 |
| AC-07-3 | `partial` 任务行出现「重试」，点击后只有文案阶段变为 `running`，生图阶段状态与图片数不变 | 同上 |
| AC-07-4 | 点击「重新生成」先出现确认文案；取消后任务数不变，确认后新增一个任务 | 同上 |
| AC-07-5 | 全部成功的任务不显示「重试」按钮 | 同上 |
| AC-07-6 | 编辑结果标题后刷新页面，标题保持新值，原始素材文字不变 | 同上 |
| AC-07-7 | 删除某个结果后，同资源夹另一个结果与原始素材均不受影响 | 同上 |
| AC-07-8 | 失败阶段展示可读原因（不含密钥与堆栈） | 同上 |
| AC-07-9 | 离开任务页后不再有新请求（轮询已停止） | 同上（监听 request 计数） |

## 验证方式

```bash
pnpm test        # 结果隔离查询、删除级联、重试接口的状态校验
pnpm test:e2e    # tests/e2e/results.spec.ts（mock 适配器）
```
